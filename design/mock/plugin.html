插件 / bowenliang123 / dsh-context

bowenliang123/dsh-context

一站式 DeepSeek Harness 上下文可视化插件。Context 面板与 /context 命令，透视组成、演进、压缩和剪枝。

作者 bowenliang123

dsh-context

The best DeepSeek Harness plugin for an agent’s context insights and management.

你会看到什么

  • Context 标签：会话统计、组成、历史、事件和当前模型可见消息。
  • /context 命令：弹出当前窗口占用、六类组成条，以及近 10 轮趋势。

Install

dsh plugin --profile web add github:bowenliang123/dsh-context#cf28676

然后执行 dsh web。不用编译，也不用重启整个 Harness。
